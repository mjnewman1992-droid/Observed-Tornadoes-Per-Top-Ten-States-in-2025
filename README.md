# Tornadoes 2025 Analysis

This project is a simple Python data visualization of observed tornado counts across the top ten U.S. states in 2025.

## Project Overview

The goal of this project is to compare the number of observed tornadoes across selected states and present the results in a clear bar chart.

The script uses manually defined state-level tornado counts and visualizes them with `matplotlib`.

## Features

- Bar chart showing tornado counts by state
- Custom color styling for each bar
- Bar labels showing exact tornado counts
- Rotated x-axis labels for readability

## Tools Used

- Python
- numpy
- pandas
- matplotlib

## File

- `Tornadoes_2025.py` — main Python script for the tornado count visualization

## Output

The script generates a bar chart displaying:

- the top ten states in the dataset
- the number of observed tornadoes in each state
- labeled values above each bar

## States Included

- Alabama
- Colorado
- Illinois
- Iowa
- Kansas
- Mississippi
- Missouri
- Nebraska
- Oklahoma
- Texas
